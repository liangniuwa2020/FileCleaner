# FileCleaner Pro - 电脑冗余与重复文件智能清理工具

基于 Python + PyQt6 开发的高性能桌面端重复与冗余文件扫描、智能分析与安全清理工具。

## ✨ 特性
- 🔍 **深度多维扫描**：支持基于文件哈希校验、文件名相似度、文件大小等多重维度的重复文件识别
- 🎯 **智能自然语言筛选**：内置自然语言解析模块，支持按时间跨度、格式类型、正则与高级规则快速定位冗余文件
- 🛡️ **安全隔离与回收保护**：支持安全移动到回收站或指定临时隔离区，防止误删重要系统文件
- 🎨 **现代化图形界面**：基于 PyQt6 打造的响应式桌面 UI，直观展现扫描结果树与磁盘占用统计

## 🚀 快速启动
```bash
pip install -r requirements.txt
python main.py
```
或直接双击运行根目录下的 `启动冗余文件清理工具.bat`。
